how to get the genius api key

1
go to genius api page

visit https://genius.com/api-clients and log in with your genius account. (or create one)

2
create new api client

click "New API Client" button and fill in the form:

  • App Name: vk lyrics fetcher
  • App Website URL: https://vk.com
3
get your access token

after submission you'll see your Client Access Token. this is your api key.

4
copy and save

copy this token and paste it in the extension popup. keep it secret tho
